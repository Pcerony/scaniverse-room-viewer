# 3Dビューア

Scaniverseで撮影した空間をブラウザで閲覧するための3Dビューアです。

公開ページ: https://Pcerony.github.io/scaniverse-room-viewer/

## 機能

- PC: WASD / 矢印キーで移動、ドラッグで視点を変更。
- スマートフォン: 左下のスティックで移動、空間をドラッグして視点を変更。2本の指で同時操作できます。
- 目線の高さ: 車いす 1.15 m、子ども 1.00 m、女性 1.50 m、男性 1.65 m。スライダーで0.60〜2.10 mに調整できます。
- 全体表示: 上部をカットしたモデルを回転・拡大縮小・平行移動できます。
- 開始位置へのリセット、対応ブラウザでの全画面表示・マウス視点固定。
- 読み込み中は受信済みデータ量に基づくパーセントと、解析・準備の段階を表示します。

高さは身長ではなく、床から目までの距離です。プリセットは体験用の目安であり、人口統計上の標準値やアクセシビリティの適合基準ではありません。

## ローカル開発

Node.js 24を推奨します。

```sh
npm ci
npm run dev
```

スマートフォンからは同じWi-Fiに接続し、ターミナルに表示されるNetwork URLを開いてください。

```sh
npm test
npm run build
npm run preview
```

GitHub Actionsが`main`へのpush時にテスト・ビルドし、`dist/`をGitHub Pagesへ公開します。相対アセットパスによりリポジトリ配下でも動作します。

## データと制限

元のOBJ・MTL・JPGは`Scaniverse 2026-10-13 210522/`にあります。表示用テクスチャは4096ピクセルへ縮小したコピーです。モデルとテクスチャは公開リポジトリ・公開ページからアクセスできます。

スキャンに含まれる欠損やぼけはそのまま表示されます。基本的な水平衝突判定と床面チェックがあり、階段・ジャンプ・重力はありません。欠損した床面は通れない場合があり、壁の穴を完全に防ぐものではありません。建築寸法やバリアフリー適合性の測定ツールではありません。

読み込みの0〜90%は実際の受信バイト数、92〜100%はテクスチャ展開・モデル解析・床面準備の段階です。圧縮通信でも展開後の受信バイト数を使用します。所要時間の推測値は表示しません。

ブラウザ回帰スクリプトは`tests/*-check.js`にあります。Playwright CLIの`run-code --filename`で実行します。スマートフォンの検証はChromiumのタッチ操作シミュレーションで、iPhone実機の性能保証ではありません。
